# Her AI Studio — Zero to Cyberdeck

We are pleased to offer a **6-week, 6-lesson curriculum** all about **local AI, training data, responsible AI, and how AI is built, using physical devices**. Each lesson includes written instructions to complete the lesson, a solution, an assignment, and more. Our project-based pedagogy allows you to learn while building — a proven way for new skills to 'stick'.

**Hearty thanks to our authors** — Jen Looper and the Her AI Studio contributors

> **Students**, to use this curriculum on your own, fork the entire repo and complete the exercises on your own, reading the lesson and completing the rest of the activities. Try to create the projects by comprehending the lessons rather than copying the solution code; however that code is available in the `/solutions` folders in each project-oriented lesson. Another idea would be to form a study group with friends and go through the content together. 

## Pedagogy

This **project-based** curriculum progreses from working on software using local models to building a hybrid software-hardware project, to launching a full-fledged cyberdeck, a small local computer that you can use to perform daily tasks, offline. By the end of week 2, students will have built their own **My Room** app with image classification, a local AI assistant, and item-management features — and will have learned the fundamentals of how AI models work, how they are trained, and how to use them responsibly.

## Each lesson includes:

- sketchnote
- written lesson
- for project-based lessons, step-by-step guides on how to build the project
- a challenge
- supplemental reading
- assignment
